# 数据字典

> 字段 / 数据结构定义。供后端、数据库、接口对齐。
> 真实 Key、学号、token 不入库、不进本文。

## 实体：questions（Supabase public，全账号共用一份）

| 字段 | 类型 | 必填 | 默认 | 说明 | 约束 |
|------|------|------|------|------|------|
| id | uuid | 是 | gen | 主键 | 唯一 |
| qtype | text | 是 | - | single / multiple / judge | 对应页面 data-questiontype 1/2/3 |
| stem | text | 是 | - | 题干原文可存，身份用规范化题干 | 规范化见 PRD 第 9 节 |
| options | jsonb | 是 | [] | 选项正文数组，不含 A) 前缀 | 顺序不进身份 |
| answer_texts | jsonb | 是 | [] | 正确选项正文或正文列表 | 回填只认正文 |
| content_hash | text | 是 | - | 题型+规范化题干+排序后选项集合 | unique btree；作答只按它查，超时 2 秒当未命中 |
| course_names | text[] | 是 | {} | 出现过的课程名，去首尾空白 | 不进 hash；upsert 追加去重；GIN 只给浏览检索 |
| source | text | 是 | - | import / extract / ai_verified | |
| verified | bool | 是 | false | 已批阅校对通过 | |
| conflict | bool | 是 | false | 两边已验证但答案不同，留旧值 | |
| updated_at | timestamptz | 是 | now | 更新时间 | |

## 2026-09-21 新增数据契约

### CourseExecutionSelection

| 字段 | 类型 | 说明 |
|---|---|---|
| accountId | string | 本机内部账号 ID，不使用明文学号 |
| scope | all 或 selected | 课程范围 |
| selectedCourseIds | string[] | 本轮选中的课程内部 ID |
| scannedAt | ISO 时间 | 本次扫描时间；重新扫描后旧选择失效 |
| locked | boolean | 任务执行期间为 true |

### QrVerificationSnapshot

| 字段 | 类型 | 说明 |
|---|---|---|
| taskId/courseId/homeworkId | string | 当前验证会话归属 |
| accountMask | string | 脱敏学生标识 |
| courseName/homeworkName | string | 弹窗显示的当前课程与作业 |
| pngDataUrl | string | 仅内存传输的二维码弹窗 PNG |
| capturedAt | ISO 时间 | 截图时间 |
| version | integer | 单调递增快照版本；刷新或任务切换后旧版本失效 |
| state | waiting/expired/verified/closed | 验证状态 |

### CourseLogEntry

字段为 time、level、accountId、courseId、homeworkId、action、result、reason。level 为 info/running/success/warning/error。禁止保存密码、Key、Cookie、token、完整门户地址、题干答案全文和二维码。

### AiConnectivityResult

字段为 model、state、latencyMs、httpStatus、errorType、message、retryAfterMs、testedAt。state 使用 pending/queued/running/success/failed；errorType 使用 missing_key/auth/model_not_found/rate_limited/network/server/timeout/empty/invalid_format。

### BankQuery 与 BankDeleteResult

- BankQuery：page、pageSize、courseName、searchMode=fuzzy|exact、searchText。
- BankDeleteResult：requestedIds、deletedIds、failed 数组和 readbackConfirmed。

### RuntimeConfigSnapshot

字段为 accountConcurrency、courseConcurrency、recommendedAccountConcurrency、recommendedCourseConcurrency、capturedAt、locked、pressureState。当前任务只读取启动时快照。

| 值 | 界面 |
|----|------|
| bank_hit | 题库答题 |
| ai_answering | AI 答题 |
| unknown_skip / ai_failed_skip | 空过 |

禁止发明「授权直通」。
