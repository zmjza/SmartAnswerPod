# 项目说明书

> 项目的源头文档：这是什么项目、为谁做、解决什么、目标与边界。
> 产品事实以正式 PRD 为准：`liran_docs/requirements/T001-开大自动答题桌面端-PRD.md`。

## 一句话定义

上海开放大学管理员自用（也可给朋友装）的 Electron 桌面自动答题器：用 Playwright 登录开大，只做每个学生「我的课程」里网上记分作业和阶段性测验中客观题且权重大于 0% 的作业。

## 解决的问题

人工逐号登录、进课、判定要不要做、扫码、逐题点选、提交、再攒题库，重复劳动大。已有自动上号器只能填账密，完不成检测、作答、提交、题库闭环。

## 目标用户

主用户是网站管理员本人；次要用户是朋友。每人在自己的安装里填学生账密、硅基流动 Key、Supabase URL 与 anon key。

## 核心价值

- 检测完自动开答，界面能看见每一步点击和题库/AI 来源
- 题库优先、AI 兜底，对的入库、库错删除，越跑越少靠 AI
- 同一学生一个浏览器，扫码只扫一次，程序自己交卷

## 项目目标

- 第一期只自动完成网上记分作业 + 阶段性测验里客观题且权重 > 0% 的作业
- 已批阅 100 分跳过；不续做；程序提交
- 题库云端一份，题干加选项集合去重，按正文回填
- macOS 与 Windows 都能装，OTA 走当前 GitHub Releases

## 边界（明确不做什么）

- 不做收藏课、视障通道、续做、实践/资源/主观题、权重 0%
- 不把自动上号器扩展拷进仓库，不嵌进 App
- 不绕过页面提交；无头使用真实 headless:true，可视化使用真实 headless:false，运行中不切换，停止释放后按新模式重启并复用 profile
- 不把密钥、学号、token 写入仓库、文档、安装包

## 2026-09-21 当前产品范围补充

- 工作模式与课程范围分离：答题/提取题库均支持全部课程和可选课程。
- 无头模式使用 Playwright headless:true 的持久化 Chromium；可视化模式使用 headless:false。作业验证通过程序内二维码完成，不因扫码把无头上下文转换成可视化。
- 题库入口包含导入和查看；查看需主进程密码门禁，查询和删除均访问真实 Supabase。
- 设置并发在空闲时实时同步，运行中按启动快照锁定；工作台本机状态和浏览器数必须来自真实采样。
- 当前 development 3/4 暂停。今晚目标是完成所有无需扫码功能；扫码后链路保留待测，不提前收口。

- 技术栈：Electron + Vite + TypeScript + Vue3；主进程产品浏览器为 patchright 捆绑 Chromium（不是原版 Playwright、不是本机 Chrome）
- 题库：新加坡 Supabase 项目一份 public.questions，含 course_names；客户端只用 publishable/anon；禁止按课拆表
- 验收：Codex 用产品 patchright 对真实开大站点跑 E2E，必须全部通过；禁止 @电脑 / Computer Use；页面样式不检查；扫码与验证码由用户配合后继续
- 登录复刻只读本机：`/Users/liran/Documents/自动上号器（扩展工具版本）`
