## 微观任务

### T007-03 非客观题隔离

- T007-03.1：删除 `subjective` 类型、文本字段元数据、AI 文本提示词和文本答案缓存。
- T007-03.2：删除 textarea/contenteditable/富文本填写、多字段顺序映射和 `answerContent` 主观匹配。
- T007-03.3：删除文件上传、上传回调等待和文件地址保存。
- T007-03.4：页面出现可见文本控件、contenteditable、文件输入或未知控件时整份作业隔离；`T007-Q05b` 覆盖 textarea、contenteditable、文本 input 和文件 input。
- T007-03.5：选择填空题保持客观，按 radio/checkbox 角色一致判型。
- T007-03.6：首题作答前按答题卡题位逐个读取真实控件，标题伪装成客观题但实际为 textarea 时也整份隔离，检查完成后回到首题。
- T007-03.7：非客观控件扫描覆盖当前题面容器，题面外层文本 input 不得漏检；文本 input 不得冒充已答客观进度。
- T007-03.8：每张可见答题卡至少有一个可点击题位；目标题位必须有明确数字题号并与当前题目位置正向匹配，缺少页面题号 x/y 时必须 fail-closed，答题卡标题不得污染当前题型判断。
- T007-03.9：英语复合题答题卡使用真实 `group.position` 和同题型 occurrence，禁止拿全局 `cardIndex` 与题目位置比较；第二张未导航卡不得复用第一组局部题号。
- T007-03.10：答题卡入口被短暂遮罩覆盖时，在总时限内保持页面不点选项并等待遮罩消失；永久遮罩有界失败。
- T007-03.11：第一篇复合题支持页面题号 `1 -> 2` 到达；第二篇答题卡当前态不得冒充第一篇目标行。
- T007-03.12：没有 `.question-card` 等答题题组容器时，当前题面可见 textarea、文本 input、contenteditable 或文件控件仍必须整份隔离；隐藏预渲染答题卡不参与可见结构判断。
- T007-03.13：同卡多复合逻辑组唯一行 1、2 必须按组和唯一行分别绑定；重复局部题号必须按 `rowIndex`、题组和导航证据唯一绑定。
- T007-03.14：复合题缺少页面题号 x/y 时返回 `skip_non_objective`，不能误归 `submit_failed`；`goTo` 行元数据必须贯穿预检、跳转和错误归因。
- T007-03.15：failure-isolation 串联覆盖首作业 `skip_non_objective`、第二作业进入真实 answer/save；首作业保存/交卷/题库写均为 0。

### T007-04 选择填空题

- 5 个 radio 题位按 `single`。
- 10 个 checkbox 题位按 `multiple`。
- 混合 radio/checkbox 或无法唯一判型时 fail-closed。
- 答题卡标题“选择填空题”不直接归主观题，以实际控件结构核对和跳转。

### T007-07 NOQR-04 答题面稳定性

- 最后保存 accepted 后，先确认 loading/network 已稳定，再进入答题卡。
- `.content-area` 变空不能仅凭签名变化判为正常页面推进。
- 混合客观卷答案卡少渲染时，只有全部保存组 accepted、可见行数等于预期组数且每行都有进度证据才允许严格兜底。
- 答题页仍禁止刷新和自动重进。
- 技术安全线后若确需隔离，必须释放账号并继续队列，不能全局人工暂停。
