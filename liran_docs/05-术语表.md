# 术语表

> 统一项目内术语/命名，避免人与 AI、文档与代码叫法不一。
> 状态码以 PRD REQ-022 为准，不得另造同义码。

| 术语 | 定义 | 同义词/别名 | 对应代码命名 |
|------|------|------------|-------------|
| 无头浏览器 | Playwright headless:true 后台运行，不创建可见浏览器窗口 | headless | display_mode=headless |
| 可视化浏览器 | Playwright headless:false 创建真实可见浏览器窗口 | headed、可视 | display_mode=visual |
| 形考两块 | 网上记分作业列表 + 阶段性测验 | 记分作业、阶段性测验 | onlineHomework / phasedTest |
| 客观题且权重>0% | 第一期要做的行 | 要做作业 | objective && weight>0 |
| 做作业 | 预览页按钮，走 doHomework | 新开作答 | doHomework |
| 续做 | 历史里的续做链接，第一期不点 | continuation | continuation.aspx |
| 题库命中 | 题型+规范化题干+排序后选项集合相同 | hash 命中 | content_hash |
| 按正文回填 | 用答案正文点选项，不用 ABCD | 选项正文 | answer_texts |
| 扫码闸门 | 同一号未验证同时只允许一份点做作业 | 验证闸门 | occupying_verify |
| 待回写 | 已交卷但未完成入库或删错 | 批阅超时记下 | pending_writeback |
| 当次上限 | 无限制最多10；≤3 最多1；其余 min(10,剩余) | 连刷上限 | attempt_cap |
| 提交成功 | 作答历史出现提交时间更新的新记录 | 不以弹窗关闭为准 | history_new_row |
| 深蓝确定 | xcConfirm 确定按钮 | 绿按钮是取消 | a.sgBtn.ok |
| slot | 浏览器名额 | 占位 | queued/launching/occupied/occupying_verify/released |
| 课程范围 | 本轮处理全部课程或只处理每生选中的课程 | 全部自动执行、可选课程执行 | course_scope=all/selected |
| 程序内作业二维码 | 只截站点真实二维码弹窗并在桌面端显示的内存 PNG | 查看作业二维码 | qr_verification_snapshot |
| 课程专属日志 | 当前学生和当前选中课程的运行日志 | 课程日志 | account_id + course_id |
| 配置快照 | 任务启动时冻结的并发设置 | 本轮并发配置 | runtime_config_snapshot |
| 题库查看门禁 | 主进程哈希校验和五次失败冻结 | 查看题库密码 | bank_unlock |
