# 未验证只点一份做作业

上级：[[_G]]
下级：无
依赖：[[预览页满分次数窗口]]

---

## 场景
同一号同时有多份要做。

## 触发
答题阶段要点做作业。

## 逻辑
同一账号的作业入口按队列调用 doHomework；二维码准备及扫码等待期间不点击其它入口。入口失败释放队列，让后续作业继续，不用永久点击计数阻断。扫码通过后刷新预览再按原生按钮进入，不 goto 作答页绕过 doHomework。入口响应期间持续检查二维码和当前作业页面，最多等待20秒。

## 状态 / 边界
本轮作业按课程顺序执行，共用该账号持久化 Context。新作答窗口只接收当前入口的 popup 或当前作业的新页面，不取已有旧作答页。
