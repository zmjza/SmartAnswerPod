# 打开可视化浏览器

> 历史名称。PRD 1.15 起，扫码主入口改为“查看作业二维码”，规则见同目录“程序内作业二维码.md”。可视化模式仍可显示同一持久化浏览器，但无头模式不再因扫码显示浏览器。

上级：[[_G]]
下级：无
依赖：[[隐藏式无头窗口]]、[[学生卡片]]

---

## 场景
历史规则：无头模式弹微信扫码或 IAM 验证码时显示已有窗口。当前作业扫码入口已改为程序内二维码；该页面只作为历史记录保留。

## 触发
用户点卡片「打开可视化浏览器」。

## 逻辑
当前实现不使用此入口切换浏览器模式。无头和可视化必须在启动时分别以 headless:true/headless:false 创建；二维码使用 [[程序内作业二维码]]。

## 状态 / 边界
点之前窗口保持隐藏。
