# 程序内作业二维码

关联：REQ-026、AC-027、TASK-G02。本文是当前扫码入口；旧“打开可视化浏览器”仅保留在历史模块中供追溯。

## 流程

1. 产品浏览器检测站点真实二维码弹窗。
2. 只截取二维码弹窗容器，生成内存 PNG。
3. 经 IPC 向桌面端发送脱敏学生、课程、作业、状态、截图时间、版本和图片。
4. 用户可复制图片、刷新二维码、关闭或点击验证完毕。
5. 验证完毕后主进程检查弹窗消失和页面可继续，成功才恢复队列。

## 边界

- 无头模式不显示浏览器，只使用程序内二维码；可视化模式保持真实窗口可见，也可使用程序内二维码。
- 二维码不会把无头上下文转换为可视化上下文，不能通过显隐、最小化或 CDP 伪装另一种模式。
- 图片不落盘、不进日志、不进题库、不进安装包。
- 任务切换后旧码失效；同一学生只保留一个有效验证会话。
- 刷新优先操作站点真实刷新入口；没有独立入口时重开当前验证弹窗并截图。每次刷新版本递增，旧版本立即失效。
- 等待扫码继续占并发名额；未确认或复核失败绝不继续。
