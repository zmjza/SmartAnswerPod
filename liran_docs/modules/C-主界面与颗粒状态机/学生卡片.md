# 学生卡片

上级：[[_C]]
下级：无
依赖：[[五层状态机]]、[[无头可视化切换]]

---

## 场景
查看当前学生。

## 触发
选中或默认当前号。

## 逻辑
显示姓名、学号和账号；隐藏专业、分校；学生按账号并行数量逐行显示，超出项从“…”菜单访问；账号并行和课程并行居中。主句拆为主状态、当前动作和进度，不重复显示。保留浏览器模式、工作模式、课程范围、日志、停止和删除能力。日志对应当前学生和当前选中课程；未选课程时禁用。无头和可视化都可打开“查看作业二维码”，扫码后必须由用户点击验证完毕并经主进程复核后继续。

## 状态 / 边界
删除释放名额。学号专业来自门户，选择器未成文则开发时补，禁止猜。
