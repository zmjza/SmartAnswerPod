# 课程范围、历史成绩与课程日志

关联：REQ-024、REQ-025、AC-025、AC-026、TASK-C03。

## 课程范围

工作模式与课程范围正交。答题/提取题库均支持全部课程和可选课程。可选课程在扫描后暂停，每个学生独立选择；开始前汇总已选学生、课程总数和未选学生；执行开始后锁定，停止后恢复。

## 历史成绩

只读获取提交次数、时间、批阅状态、分数、是否完成和可靠查看入口，按最新提交优先。不得续做、答题、提交或触发题库回写。

## 课程日志

日志键为当前学生内部 ID + 当前课程 ID。未选课程时禁用。事件覆盖检测、历史、页面、题目、题库、AI、回填、补答、提交、成绩、校对、删错、二维码、网络、暂停和停止；五级颜色为蓝灰/蓝/绿/橙/红。禁止写入账密、Key、Cookie、token、完整 URL 和二维码。

## 状态展示

主进程只推送一套主状态、当前动作和进度。渲染层不得产生重复状态。学生卡刷新和顶栏头像删除，状态区按当前事实重新排版。
