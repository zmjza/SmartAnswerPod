# 无头可视化切换

上级：[[_C]]
下级：无
依赖：[[隐藏式无头窗口]]

---

## 场景
用户要看或藏某生窗口。

## 触发
点卡片右上角无头/可视化。

## 逻辑
这是启动模式选择，不是同一上下文的显隐开关。无头启动使用 headless:true，可视化启动使用 headless:false。运行中的学生禁止切换；停止并释放后才允许按新模式重新启动，登录态通过同一持久化 profile 保留。无头扫码使用程序内二维码弹窗，可视化模式同时保留真实浏览器窗口和程序内二维码入口。

## 状态 / 边界
切换失败必须回传真实原因，不能先改 UI 再假报成功。模式按钮只在空闲时可修改，运行中显示锁定原因。禁止使用 CDP、macOS 隐藏窗口或同一 PID 显隐来伪装模式切换。禁止放进顶栏。
