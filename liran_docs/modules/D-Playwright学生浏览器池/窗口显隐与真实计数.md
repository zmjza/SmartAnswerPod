# 窗口显隐与真实计数

关联：REQ-030、AC-031、TASK-D02。

- 无头使用 Playwright headless:true，后台没有浏览器窗口。
- 可视化使用 Playwright headless:false，显示真实浏览器窗口。
- 两种模式分别启动上下文；运行中的模式锁定，切换必须停止任务后重新启动，复用同一学生 profile 和登录态。
- 无头提取和无头扫码全程不显示窗口。
- 浏览器数严格为 launching + occupied + occupying_verify，不含排队。
- 创建、占用、验证暂停、释放和崩溃都必须推送新计数。
- 无头模式的真实窗口可见性固定为不可见；可视化模式必须从真实窗口状态确认可见。UI 标签不得只依赖本地按钮状态。
- 任务结束保留持久化 profile 和登录态。采样失败显示 unavailable/error，不沿用旧值。
