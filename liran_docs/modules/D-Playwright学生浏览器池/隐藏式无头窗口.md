# 隐藏式无头窗口

上级：[[_D]]
下级：无
依赖：[[名额占用与释放]]

---

## 场景
默认运行自动化。

## 触发
launch 成功后。

## 逻辑
按 display_mode 在启动时选择 Playwright 运行方式；两种模式都先进入学习中心登录链，登录流程不因模式改变：

- \`headless\` 使用 \`headless: true\`，后台运行，不创建可见浏览器窗口。
- \`visual\` 使用 \`headless: false\`，创建真实可见浏览器窗口。

两种模式都使用该学生自己的持久化 profile。上下文启动后不能动态互换 headless/headed；切换模式必须先停止并释放旧上下文，再按新模式重新启动并复用 profile。无头扫码只通过程序内二维码弹窗，不显示浏览器窗口。可视化模式始终显示真实浏览器窗口，不能用窗口隐藏来冒充无头。

## 状态 / 边界
运行中的上下文模式锁定。运行中点击另一模式必须拒绝并说明“停止任务后重新启动才能切换”。模式切换不是窗口显隐操作，也不能用 CDP、macOS 原生隐藏或移动窗口伪装成无头。
