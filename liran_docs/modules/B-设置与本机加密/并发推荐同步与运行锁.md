# 并发推荐、配置同步与运行锁

关联：REQ-031、AC-032、TASK-B03。

## 规则

- 推荐输入为 CPU 核心与使用率、总/可用内存、软件占用、浏览器平均内存和压力状态。
- 推荐账号并发与课程并发只作建议，不强制覆盖用户值。
- 空闲保存后主进程广播，设置页、工作台和学生卡统一更新。
- 保存或广播失败显示原因并保留上一份有效配置。
- 任务启动时固化配置快照；运行中渲染控件和会修改并发的恢复默认禁用，主进程也拒绝并发修改。
- 任务全部结束或停止后恢复编辑。

## 测试

按 09 的 T15-H01 至 T15-H11 逐项实测，不允许用单一“设置保存成功”替代同步、锁定和恢复证据。
