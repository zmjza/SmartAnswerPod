# Excel导入账号

上级：[[_B]]
下级：无
依赖：[[设置页字段]]

---

## 场景
用户有一批学生账密表。

## 触发
选择三列 Excel（姓名、账号、密码），跳过表头。

## 逻辑
写入本机账号列表，密码进 safeStorage。可添加多个。新增复制粘贴批量导入：每行姓名、账号、密码，支持 Excel 复制内容、CSV、Tab、英文逗号、中文逗号、空格和换行；先解析预览，再二级确认，确认框三项明文显示，确认后复用同一写入链。

## 状态 / 边界
坏行、重复账号、空行和表头按预览结果提示行号和原因；取消确认不写入。参考图样本姓名学号不当默认数据。批量粘贴由模拟数据 E2E 验证。
