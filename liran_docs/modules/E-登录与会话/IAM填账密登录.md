# IAM填账密登录

上级：[[_E]]
下级：无
依赖：[[凭据safeStorage]]、[[已有页面结构索引]]

---

## 场景
检测开始。

## 触发
对该生持久化 Context 先打开学习中心 /scenter。未登录时由学习中心门户自动跳转到带上下文的 IAM 登录页；不得直接拼接无 lck 的 IAM 首页。登录成功后由门户回到学习中心，目标是课程页 #tab-courseList。

## 逻辑
从本机安全存储读取账号密码，填入 IAM 登录组件的账号和密码字段，并同步组件模型后调用 submitLogin()。登录成功后等待门户回跳；若落在 /login，只按门户既有回跳链回到 /scenter，不直接伪造 token 或拼接完整门户参数。确认 #tab-courseList 存在并进入学习中心后，才开始课程扫描。

## 状态 / 边界
错密停该号，其他学生继续。连续重登失败停该号。IAM 验证码、人脸、微信验证和作业扫码统一进入验证闸门；验证前不扫描课程、不开始作业。账号密码输入必须清理 Markdown 行尾续行反斜杠，不能把反斜杠保存进凭据。选择器待补则标受阻，不编造。
