# 状态日志与凭据脱敏

上级：[[_N]]

## 状态

显示登录、课程检测、作答、等待保存、提交、等待批阅、获取分数、重答、停止和异常暂停阶段。显示当前课程/作业、题号/总题数、题库/AI 计数、重答次数和真实等待时长；每份实际作答作业显示平均每题、最长单题和完成总时长，统一“X分YY秒”，不显示毫秒；不显示提取题库写入统计。

## 日志

- 复用现有 `log_enabled`。
- noqr 不向旧 `electron/progress.ts` 全局事件总线发送进度；使用独立状态快照，由 workbench-coordinator 合并。
- 关闭详细日志仍保留当前状态、错误摘要和结果。
- 日志失败不得改变主流程成功判定。
- 内部夹具、真实站点和真机证据分区记录，不能互相冒充。

## 凭据与证据

不得写入或输出：

- 账号、密码、Cookie、token。
- 完整 URL 参数、真实 workId、homeWorkUniqueFlag、paperStructUniqueFlag、学校内部 ID。
- 完整题干/选项/答案正文。
- 音频地址、截图中的账号信息或二维码原图。

真机测试只使用 `NOQR-01`、`NOQR-02`、`NOQR-03`、`NOQR-EN` 等别名和运行时凭据，证据记录状态、计数、耗时类别和脱敏结果。

T005-A12、T005-R01～R19 与 N58～N74；敏感字段静态扫描和运行日志复核。
