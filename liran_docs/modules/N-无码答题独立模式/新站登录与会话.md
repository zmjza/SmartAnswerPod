# 新站登录与会话

上级：[[_N]]

## 唯一入口

只从 `https://coursework.shou.org.cn/login/index.html` 进入，不直接打开首页、课程、答题或记录深链。

## 页面事实

| 元素 | 选择器/判断 |
| --- | --- |
| 用户名 | `input[name="用户名"]` |
| 密码 | `input[name="密码"]` |
| 提交 | 文本“提交” |
| 登录中 | 文本“加载中...” |
| 首页业务标记 | `.menu-items` 或 `.course-card` |

## 状态机

1. 打开登录页，判断是否有有效会话。
2. 无会话则填写现有账号密码并提交；有会话则观察是否自动进入首页。
3. 登录中持续等待，按钮/加载状态可见，不按固定秒数刷新或重复提交。
4. 成功：URL 到 `/index.html`、登录表单消失、首页业务标记出现。
5. 登录失败：仍在登录页、表单可见，并有明确错误/HTTP 4xx/5xx；或加载结束且无网络活动仍无法进入首页。
6. URL 已到首页但内容空白：归类“登录成功但首页加载失败”，刷新首页恢复，不重新提交登录。
7. 验证码、扫码、企业微信、人脸或异常授权：暂停通知用户，不绕过、不伪造 token、不自动进入旧扫码流程。

## 隔离要求

- 只使用独立 `electron/noqr/session.ts` 和 `electron/noqr/selectors.ts`。
- 不调用旧 `login.ts`、旧扫码闸门、旧 `markVerify` 或旧授权状态。
- 登录凭据只从现有账号/安全存储运行时读取，日志与证据不输出账号、密码、Cookie、token 或完整 URL。

## 验收

T005-A02、N01～N08：会话复用、慢登录、错误密码、登录页空白、首页空白、会话失效和异常验证。
