# 课程与作业检测

上级：[[_N]]

## 课程入口

- 从新站首页点击“形考作业”。
- 右上角课程菜单使用 `.van-popover__action.top-pop-item`，当前课程使用 `.top-pop-active`。
- “中文”“English”“切换课程”是语言/操作默认项，不是课程；必须过滤，不进入课程快照、选课、检测、分页和并发。真实课程保留原始 DOM 序号用于点击。
- 课程数量、名称、顺序按真实菜单读取，不写死。
- 逐门切课并等待当前课程 `.work-item` 或明确空态；上一门课残留不能冒充当前课程。
- 同一学生共享一个 persistent context；课程并发 `N` 表示最多 `N` 个独立页面/lane 同时推进，在单个页面上切课必须串行。

## 范围与分页

- 沿用全部/可选课程、学生课程快照、课程分页和课程状态。
- 分页只影响工作台展示，不截断扫描或执行范围。
- 一门课程为空、失败、未知 workType 或第三方嵌入不得阻断其它课程。

## 作业规则

- 入口 URL 的 `workType` 白名单精确为 `onlineWork`、`stageExam`。
- 作业卡“客观题”标签只用于筛候选，不得覆写 URL `workType`；点击后以实际 URL 为准，其他值停止并隔离。
- 作业卡 `.work-item`、作业名 `.work-title`、开始作答 `.work-btns .btn-item:nth-child(1)`、作答记录 `.work-btns .btn-item:nth-child(2)`。
- 复用日期窗口、满分跳过、次数上限、网上记分作业/阶段性测验规则。
- 生产环境不显示测试强制开关；测试环境开关默认关闭、进程级、不持久化、测试结束恢复。
- 全部或大部分账号已完成/满分：先走自然重答；自然规则跳过时启用测试开关继续真实答题测试，不把满分当验收阻塞。

## 空白恢复

- 非答题页无目标 DOM、无骨架、无错误、无活动请求时按预算刷新。
- 有活动请求或骨架时继续等待。
- 连续刷新仍无作业，只标记当前课程本轮暂无可见作业，不阻断其它课程。
