# 空白恢复、停止与异常

上级：[[_N]]

## 空白分类

- 文档加载中：继续等待。
- 骨架加载中：继续等待。
- 正常就绪：进入业务流程。
- 无活动空白：按页面类型决定刷新或停止。
- 明确错误：记录脱敏原因，作业级/课程级隔离。

## 刷新矩阵

| 页面 | 允许刷新 | 处理 |
| --- | --- | --- |
| 登录页/首页 | 是，按恢复预算 | 有活动请求先等待；无活动空白刷新 |
| 形考作业/课程列表 | 是，按恢复预算 | 连续刷新仍无作业只标记当前课程无作业 |
| 答题启动骨架 | 否 | 返回作业区，重新点击开始作答 |
| 已产生作答进度的答题页 | 禁止 | 不刷新、不自动返回重进，等待或由用户停止 |
| 交卷成功/记录页 | 是，按恢复预算 | 只有标题、无 `.record-item` 且无明确空态时先防抖，再按预算刷新；交卷后暂时空态等待新记录 |

非答题页统一按 60 秒无活动、90 秒重复心跳和 120 秒持续活动请求分级识别，最多进行 3 次有界恢复。慢业务请求未结束时不得刷新；请求结束并从完成时刻重新计算完整静默宽限。答题页无论加载还是保存阶段均禁止刷新、自动重进或重建上下文。

## 停止状态机

1. 用户点击停止后立即禁止下一题、交卷和新作业动作。
2. 若当前保存/交卷请求已发出，等待原子请求结束并记录。
3. 若无法确认结果，标记“结果不确定”，不自动重发。
4. 释放页面、浏览器和 slot；不重建会话，不继续点击。

## 异常验证

- 二维码、企业微信、验证码、人脸、二次认证：暂停并通知用户。
- 不进入旧扫码/验证流程，不伪造 token、Cookie 或验证状态。
- 用户处理后按原任务状态继续；不能继续时保持暂停/受限。

## 不支持场景

普通填空、简答、问答、论述、主观、富文本、文件上传、未知题型、未知控件、未知 `workType`、第三方嵌入、结构缺失或不可恢复错误只停当前作业/课程，记录脱敏原因，继续其它任务。出现可见文本控件、contenteditable 或文件控件时，整份作业隔离，不保存、不交卷。
