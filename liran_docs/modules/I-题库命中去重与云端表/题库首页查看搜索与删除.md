# 题库首页、查看、搜索与删除

关联：REQ-028、REQ-029、AC-029、AC-030、TASK-I02。

## 首页与门禁

题库页显示导入题库和查看题库两张卡片。查看前由主进程校验约定密码的不可逆哈希；五次错误冻结 60 秒，重启不能绕过。

## 查询

对 public.questions 做服务端分页，支持课程筛选、模糊/精确搜索、清除和每页数量。表格显示序号、课程、题干、选项、答案、更新时间和操作。

## 删除

单删与批删均二次确认；主进程执行真实删除并回读。部分失败逐条返回，不得显示全部成功。

## 导入测试

临时测试题必须带独立批次标识，覆盖新增、重复、跨课程合并、选项乱序、已验证答案冲突、缺字段、空值、未知题型、非法 JSON、替换字符、写入失败和回读失败。写入和回读失败必须进入独立失败计数，界面不得显示全部成功；合法空数组显示本次导入完成且统计为零。结束只删除本批并回读确认，同时抽样确认非本批真实题目未变化。
