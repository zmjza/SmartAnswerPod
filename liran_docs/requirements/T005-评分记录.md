## 范围上限

只新增一个独立无码答题工作模式及其必要页面适配、状态、日志、测试、版本与本地打包。不重构现有答题/提取模块，不修改扫码授权协议，不新增题库写入，不扩展未观察题型，不重做工作台视觉，不进行 Release、Tag、OTA 或安装包上传。

## 安全门禁

- 无码运行期间云端题库写操作为 0，本机 writeback/extract_writeback 新增为 0。
- 现有 `answer/extract`、扫码、提交、批阅和题库回写逻辑不得被新分支反向依赖或改变行为；无码业务必须落在独立模块，旧分支不得新增无码页面条件，旧模块不得 import 无码实现。
- 答题页禁止刷新；答题启动空白只能返回作业区重进。
- 保存成功必须同时具备 L1 新请求、L2 HTTP 2xx/业务 `success:true`、L3 页面推进或最后一题提示。
- 验证失败、真实题库写入、旧模式回归破坏、封装产物夹带敏感数据均为阻断项。

## 项目级完整条件

当前不是新项目、技术栈迁移、整体架构重构或多个大型独立模块同时改造；虽有跨模块改造，但范围仍可限定为一个新增工作模式及必要消费者。不成立完整流程条件。
