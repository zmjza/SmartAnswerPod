# 避坑知识库

## 用途

记录本项目开发、修复、测试、部署、排障中已经验证过的坑，避免重复踩。

发布与 OTA 专题：[ota-release.md](ota-release.md)。

## 读取规则

任何 Codex/AI 做开发、修复、测试、部署或排障前：

1. 先读项目根 `AGENTS.md`
2. 再读本 README
3. 再读相关模块文件；无法分类时读 `general.md`

## 写入规则

- 新坑必须在任务收尾前追加写入对应文件
- 任务中断也尽量记录已发现但未提炼的坑
- 只追加，不删除旧条目，不覆盖旧内容
- 禁止写入密钥、token、账号密码、隐私数据、生产配置全文、完整敏感日志
- 信息不全必须标注「信息不全，待人工补充」或「以下为基于现有证据的推测」
- 禁止编造根因、报错、数值或验证方式

## 历史回填

- 历史回填只做一次
- 回填状态：已完成（跳过）
- 跳过原因：建立知识库时仓库为空目录，无 git、无业务代码、无 README/包描述、无开发文档、无测试/部署记录；当前对话仅规划本机制，没有已验证技术坑
- 后续只增量追加，不再全量回扫历史

## 条目格式

每条坑使用 Markdown 二级标题，必须包含：

- 现象
- 根因
- 正确做法
- 验证方式
- 禁止事项
- 相关文件或命令
- 适用范围
- 来源（git / 文件 / 对话 / 验证）
