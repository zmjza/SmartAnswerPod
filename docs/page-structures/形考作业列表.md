# 形考作业列表

课程壳点「形考作业」后的页。自动化只处理用户点名的两块：网上记分作业列表、阶段性测验。其它面板记下来避免误点，第一期不做。

- 证据：用户给的有作业 HTML、无作业 HTML；Chrome 两门样本课只读核对。
- 路径：`/study/HomeWorkNew.aspx`
- 查询参数：`courseOpenId`、`minorcourseopenid`

## 1. 用户要判的两种大情况

### 1.1 无作业

标题直接写死「暂无数据」，没有表格：

```html
<div class="am-panel-hd">
  <h3 class="am-panel-title"><span class="am-icon am-icon-file-o"></span>网上记分作业列表：暂无数据</h3>
</div>
<div class="am-panel-hd">
  <h3 class="am-panel-title"><span class="am-icon am-icon-file-o"></span>阶段性测验：暂无数据</h3>
</div>
```

判定：对应块标题包含 `：暂无数据` → 该块状态 = 无作业。

两块都无作业 → 这门课形考作业标记为无作业，进入下一门课。

### 1.2 有作业

有 `am-panel-default` + 表格。用户规定按行再分三种：

| 条件 | 状态 | 动作 |
| --- | --- | --- |
| 题目类型含「客观题」，且权重解析后 > 0 | 要做 | 点该行「查看」 |
| 题目类型含「客观题」，且权重是 0% | 不需要做 | 只标记，不点 |
| 题目类型不是客观题 | 要做 | 用户原话要做；作答页结构还没有，待确认怎么答 |

第一期产品规则（需求整理已确认，页面仍可能出现这些行）：只做这两块里的「客观题且权重>0」。非客观题、课程实践、资源学习都跳过并标记。已批阅 100 分的作业在预览页跳过，见 [作业预览-作答历史.md](作业预览-作答历史.md)。

权重示例：`20%`、`100%`、`0%`。去掉 `%` 再比大小。

## 2. 两块怎么定位

| 块 | 有数据时标题 | 有数据时容器 | 无数据时标题 |
| --- | --- | --- | --- |
| 网上记分作业 | `网上记分作业列表`（没有冒号） | `#onlineHomework table.am-table` | `网上记分作业列表：暂无数据` |
| 阶段性测验 | `阶段性测验` | `#phasedTest table.am-table` | `阶段性测验：暂无数据` |

不要用「页上有没有 table」一刀切：同一页可以一块有、一块无。

样本：

| 样本 | 网上记分作业 | 阶段性测验 |
| --- | --- | --- |
| 工商企业经营管理 | 有 2 行客观题 20% | 暂无数据 |
| 形势与政策（1） | 暂无数据 | 有 1 行客观题 100% |

## 3. 有数据时的表头（两块一样）

用户 HTML：

| 列序 | th 文案 | th id | 用途 |
| --- | --- | --- | --- |
| 1 | 序号 | 无 | 列表序号，不要当作业 ID |
| 2 | 名称 | `Title` | `td` 有 `title` 全名，可见文本可能截断 |
| 3 | 类型 | `PaperType` | 网上记分作业 / 线上阶段性测验 |
| 4 | 题目类型 | `WorkType` | 是否客观题 |
| 5 | 权重 | `Weight` | `20%` / `100%` / `0%` |
| 6 | 形考开始时间 | `StartReplyDate` | `td[title]` 是完整时间 |
| 7 | 形考结束时间 | `EndReplyDate` | 同上 |
| 8 | 作答次数 | `ReplyCount` | 可见 `1/无限制` 或 `2/无限制`；内有 hidden |
| 9 | 操作 | 无 | `查看` |

表：`table.am-table.am-text-center`，`data-orderbys` 一长串字段名，自动化不用排序。

## 4. 行字段怎么取

对 `#onlineHomework tbody tr` 和 `#phasedTest tbody tr` 各扫一遍。

| 字段 | 取法 |
| --- | --- |
| 序号 | 第 1 个 `td` 文本 trim |
| 名称 | 第 2 个 `td` 的 `title` 优先，否则文本。样本全名「记分作业一」「26秋《形势与政策》（1）测试题」，可见可能是「26秋《形势与政策》（...」 |
| 类型 | 第 3 个 `td` 的 `title` 或文本 |
| 题目类型 | 第 4 个 `td` 文本，判断是否包含「客观题」 |
| 权重文本 | 第 5 个 `td` 文本 |
| 权重数字 | 解析百分号前的数字 |
| 开始/结束 | 第 6、7 个 `td` 的 `title`（`2026/8/18 0:00:00`）或可见日期 |
| 已作答次数可见值 | 第 8 个 `td` 文本，样本 `1/无限制`，红色字「无限制」 |
| replyCount hidden | `input[name=replyCount]`。用户 HTML 值是 `-1`（无限制）。只读 Playwright 有时读成空，以用户 HTML / CDP 为准 |
| 查看 | 最后一列 `a[href*="assignment-preview.aspx"]`，`target=_blank`，文案「查看」 |

查看的 href：

```text
/study/assignment-preview.aspx?homeWorkId=...&courseopenid=...&minorCourseOpenId=...
```

参数名：`homeWorkId`、`courseopenid`（全小写）、`minorCourseOpenId`。进的是预览页，不是作答页。

## 6. 本页还有、第一期不处理的面板

现场 `HomeWorkNew.aspx` 同一页还有（避免扫到误点）：

| 标题 | 样本 |
| --- | --- |
| 课程论文考 | 暂无数据 |
| 书面作业 | 暂无数据 |
| 课程实践 | 工商样本有「企业经营环境分析报告」，线上实践，权重 40%，操作查看进 `/study/laboratoryInfo/preview.aspx` |
| 小组活动 | 表格一行「暂无数据」 |
| 学习表现 | 暂无数据 |
| 上课出勤得分 | 暂无数据 |
| 观看在线资源 | 工商样本有「观看在线资源 20% 资源(包含视频) 点击记分」 |
| 在线练习(不计分) | 暂无数据 |

用户原话只检测网上记分作业列表和阶段性测验。课程实践 40% 是否以后做，待确认。第一期不要点实践「查看」。

阶段性测验面板下方可能有红色 `strong`：补考学期限制说明。自动化忽略文案，不要当作业行。

## 7. 推荐采集对象（每条作业一行）

| 字段 | 来源 |
| --- | --- |
| section | `onlineHomework` / `phasedTest` / `empty` |
| name | td title 或文本 |
| paperType | 网上记分作业 / 线上阶段性测验 |
| workType | 客观题 / 其它原文 |
| weightPercent | 数字 |
| needDo | 按第 1.2 节规则 |
| skipReason | 无作业 / 客观题权重0 / 非客观题待策略 |
| previewHref | 查看链接 |

## 8. 本页最小流程

1. URL 已是 `HomeWorkNew.aspx`。
2. 读网上记分作业块：暂无数据或逐行判定。
3. 读阶段性测验块：同上。
4. 对 `needDo` 的行依次点「查看」（`_blank`），进入 [作业预览-作答历史.md](作业预览-作答历史.md)。
5. 两块都做完或都无作业 → 下一门课。

## 9. 硬坑

- 无数据时没有 `#onlineHomework` / 没有行，只能靠标题 `：暂无数据`。
- 「查看」打开的是 `assignment-preview.aspx`（没有中间 `/`），不是作答页。
- 名称列会截断，匹配题库/展示进度用 `title` 全名。
- 权重 0% 的客观题按用户规则跳过，即使有「查看」。
- 同页课程实践也有「查看」，选择器必须限定在 `#onlineHomework` 或 `#phasedTest`。
