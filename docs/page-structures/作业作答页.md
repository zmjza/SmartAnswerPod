# 作业作答页

真正答题、逐题保存、提交作业的页面。

完整契约已经写在仓库根目录，不在这里复制一份：

[开大自动答题页面结构.md](../../开大自动答题页面结构.md)

- 路径：`/study/assignment/preview.aspx`
- 题型：单项选择题、多项选择题、判断题
- 选项是 `li.e-a[data-index]`，没有原生 radio/checkbox
- 权威已做：该题 `form [name=answer]` 非空
- 多选题必须多选，answer 是逗号串
- 判断题 `data-index`：1=正确，0=错误
- 右侧题号已做看 `a.e-item.active`（青底白字），不要看 `notdo`
- 提交走 `#submitHomeWork` → `xcConfirm`，深蓝确定、绿色取消

从预览页「做作业」进来；提交成功会跳回 `/study/assignment-preview.aspx`。
