# 课程学习 · 形考作业入口

从「我的课程」点进某门课后，先点左侧「形考作业」。用户本轮只给了这个节点。

## 1. 用户给的节点（权威）

```html
<a id="courseHomeWorkNew" href="HomeWorkNew.aspx?courseOpenId=...&minorcourseopenid=...">
  <dd class="jxri">形考作业</dd>
</a>
```

| 项 | 值 |
| --- | --- |
| 选择器 | `a#courseHomeWorkNew` |
| 可见文案 | `dd.jxri` = 形考作业 |
| href | `HomeWorkNew.aspx`（相对当前 `/study/`） |
| 查询参数 | `courseOpenId`、`minorcourseopenid`（大小写按页面原样，不要改） |

点它进入 [形考作业列表.md](形考作业列表.md)。

## 2. 这个入口出现在哪

课程学习壳的左侧导航。用户原话是：课程打开后「首先先去点击」这个链接。

Chrome 在 `HomeWorkNew.aspx` 上也能看到同一个 `#courseHomeWorkNew`，说明进了形考页后侧栏还在。自动化只要能点到 `#courseHomeWorkNew` 或已经在 `HomeWorkNew.aspx` 就算到达。

课程名链接默认打开的是：

```text
/study/learnCatalogNew.aspx?courseOpenId=...&minorCourseOpenId=...
```

学习目录页全文本轮没有 HTML，不在这里展开。缺页时只要确认 `#courseHomeWorkNew` 存在再点。

## 3. 同侧栏其它项（现场补充，本期不点）

HomeWorkNew 现场侧栏，避免以后点错：

| id | dd 文案 | 路径 |
| --- | --- | --- |
| `courseInfoNew` | 课程信息 | `/study/courseInfoNew.aspx` |
| `learnCatalogNew` | 学习目录 | `/study/learnCatalogNew.aspx` |
| `courseHomeWorkNew` | 形考作业 | `/study/HomeWorkNew.aspx` |
| `activityNew` | 教学活动 | `/study/activityNew.aspx` |
| `StudyArchivesNew` | 形考查分 | `/study/viewScoreNew.aspx` |
| `calendarNew` | 教学日历 | `/study/calendarNew.aspx` |
| `bbsNew` | 课程讨论区 | `/study/bbs.aspx` |
| `evaluationNew` | 课程评价 | `/study/evaluationNew.aspx` |
| `knowledgeNewMap` | 资源访问情况 | `/report/OnlineIndex.aspx` |

顶部还有课程切换链接（样本：工商企业经营管理 / 形势与政策（1） / 社会调查（工商专）），点了会换课。按「我的课程」顺序做时不要点这些切换。

## 4. 本页最小流程

1. 当前页已是课程壳（目录或形考都算）。
2. 等待 `a#courseHomeWorkNew`。
3. 点它。
4. 等到 URL 含 `HomeWorkNew.aspx`，再读作业列表。

## 5. 硬坑

- 参数名 `minorcourseopenid` 在这个 href 里是全小写；门户课程链接里是 `minorCourseOpenId`。读 href 用 URLSearchParams，不要手拼大小写。
- 用户流程是先课程再形考作业，不要第一期就改成直接打开 HomeWorkNew（可以当备用，但默认跟用户走）。
