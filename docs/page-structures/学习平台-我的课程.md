# 学习平台 · 我的课程

登录成功后的统一学习门户。自动化在这里数课程、按 DOM 顺序进入课程。

- 证据：用户提供的 `el-card__body` / `el-tabs` HTML；Chrome 打开的 `/scenter` 只读核对过课程数、Tab、进度文案。
- 页面标题：统一学习门户首页
- 主机：`learning.shou.org.cn`（后面课程链接会跳到 `l.shou.org.cn`）

## 1. 入口 URL

```text
https://learning.shou.org.cn/scenter
```

查询参数只记名字，禁止把值写入仓库、日志、截图文件名：

| 参数 | 用途 |
| --- | --- |
| `xh` | 学号。禁止采集、禁止打印 |
| `xhtoken` | 门户令牌。禁止采集、禁止打印 |
| `timespan` | 时间戳 |

自动化打开本页时用已登录会话，不要去拼带 `xh` / `xhtoken` 的 URL 写进代码。

## 2. 整页骨架

```text
.el-card__body
└─ .el-tabs.el-tabs--top.tabs
   ├─ .el-tabs__header.is-top
   │  └─ .el-tabs__nav-wrap > .el-tabs__nav-scroll > .el-tabs__nav[role=tablist]
   │     ├─ .el-tabs__active-bar
   │     ├─ #tab-courseList.el-tabs__item     我的课程
   │     └─ #tab-collections.el-tabs__item    收藏课程
   └─ .el-tabs__content
      ├─ #pane-courseList.el-tab-pane         默认可见
      │  └─ .course-item × N
      └─ #pane-collections.el-tab-pane        默认 display:none
```

样本现场：`#pane-courseList` 计算样式 `display:block`，`#pane-collections` 为 `none`。

## 独立置顶课程卡（2026-09-27 Chrome 只读核对）

- `/scenter` 的“我的课程”Tab 上方另有一张独立卡片，当前样本标题为“形势与政策（2）”。它仍用 `.course-item > .el-row > .course-info > p.course-title` 结构，但位于另一张 `.box-card .el-card__body .el-tabs__content > .course-item` 中，不是 `#pane-courseList` 的后代。当前 Tab 内为 7 门，独立卡另有 1 门。
- 课程名链接指向 `/study/learnCatalogNew.aspx`，卡内“记分作业”链接指向 `/study/HomeWorkNew.aspx`；点击课程名会另开课程学习页，侧栏有“形考作业”入口，进入 `/study/HomeWorkNew.aspx`。本样本“网上记分作业列表”为空，“阶段性测验”有 1 行；不要只因记分作业进度或空列表就跳过阶段性测验。
- 采集时先从 Tab 外单独识别这张置顶课程卡，再合并 `#pane-courseList .course-item`；不要用全页面 `.course-item` 无条件抓取其他区域，也不要把“我的消息”里的同名课程评价链接当课程卡。标题后缀可能是（1）／（2）／（3），以实际卡片名称和链接为准，不固定学号、课程 ID 或后缀。若同一课程也出现在 Tab 内，按课程链接中的课程标识去重，避免重复扫描。
- 以上仅证实当前账号的页面形态和导航；不同账号是否显示该卡、不同后缀及已批阅作业细节仍待后续样本验证。下文仅描述 Tab 内原有列表。

## 3. Tab

| 选择器 | 文案 | 默认 |

## 4. 怎么数课程

```text
#pane-courseList .course-item
```

旧样本现场为 2 门；2026-09-27 样本 Tab 内为 7 门，另有 1 门独立置顶课。不要写死数量，以当次合并去重结果为准；Tab 内保持 DOM 顺序，置顶课在前。

## 5. 单门课程 `.course-item`

```text
.course-item
└─ .el-row
   ├─ .el-col.el-col-17
   │  ├─ .course-info
   │  │  ├─ p.course-title
   │  │  │  └─ .el-badge.badge-item
   │  │  │     ├─ a.el-link[title=点击进入学习][target=_blank]
   │  │  │     │  └─ span.el-link__inner     课程名 + 右侧小图标
   │  │  │     └─ sup.el-badge__content     记分说明徽标
   │  │  └─ p.teacher-group
   │  │     └─ span × 主持教师 / 辅导教师 / 辅导员
   │  ├─ .course-process

   │  │  └─ .process-item

   │  │        ├─ 面授出勤率

   │  └─ .comment                     学习建议
   └─ .el-col.el-col-7

```

### 5.1 课程名

| 字段 | 选择器 | 说明 |
| --- | --- | --- |
| 课程名 | `.course-title a.el-link .el-link__inner` | 文案里夹着 SVG 图标，取 text 后 trim |
| 进入学习 | `.course-title a.el-link[title="点击进入学习"]` | `target=_blank`，href 是 `/study/learnCatalogNew.aspx` |
| href 参数 | 只记名字 | `courseOpenId`、`minorCourseOpenId` |

样本课程名（只作识别示例，不要当白名单）：

- 工商企业经营管理
- 社会调查（工商专）

### 5.2 徽标

`sup.el-badge__content.el-badge__content--danger.is-fixed`

| 样本文案 | display | 含义 |
| --- | --- | --- |
| 含观看在线资源客观记分（权重:20%） | `flex`（可见） | 这门课有客观记分资源 |
| 含观看在线资源主观记分（权重:0%） | `none`（DOM 在，看不见） | 权重 0，徽标被藏起来 |

不要用徽标判断「要不要做作业」。做作业以形考作业列表为准。

### 5.3 教师

`p.teacher-group span`，样本三项：主持教师、辅导教师、辅导员。自动化不依赖。

### 5.4 进度四块

都在 `a` 里，文案是「标签：值」。

| 文案前缀 | href 路径 | 样本值 |
| --- | --- | --- |
| 资源学习进度： | `/study/learnCatalogNew.aspx` | `58.00%` / `0.00%` |
| 直播出勤率： | `/study/activityNew.aspx` | `0.00%` / `无` |
| 面授出勤率： | `/study/activityNew.aspx` | `0.00%` |
| 记分作业： | `/study/HomeWorkNew.aspx` | `100.00%` / `无` |

「无」和「0.00%」不是一回事：

- `无`：这门课没有这项（样本：社会调查的直播出勤率、记分作业）
- `0.00%`：有这项，当前是 0
- `100.00%`：有这项且已满（不代表形考列表一定无作业，仍要进列表核对）

用户流程是进课程后再点「形考作业」，不要自作聪明只点「记分作业」进度链。进度链可以当备用直达 `HomeWorkNew.aspx`。

进度条 `ul.graph > li.li-day[data-progress]` 自动化忽略。

### 5.5 学习建议

`.comment` 内有图标 + `<b>学习建议：</b>` + 一段话。自动化忽略。

## 7. 推荐采集对象（每门课一条）

| 字段 | 来源 |
| --- | --- |
| index | 合并置顶课与 Tab 课程并去重后的序号，从 0 或 1 皆可，保持稳定 |
| name | `.el-link__inner` 文本 |
| catalogHref | 课程名链接 href（只存路径+参数名，或运行时对象，不要把门户 token 带出去） |
| homeworkHref | 「记分作业：」那条 `a` 的 href，备用 |
| scoreHomeworkText | 「记分作业：」后面的 `100.00%` / `无` 等 |

## 8. 本页最小流程

1. 确认 `#tab-courseList.is-active`，否则先点它。
2. 若存在独立置顶的“形势与政策（数字）”课程卡，读取其课程名链接；再取 `#pane-courseList .course-item` 全部，合并并按课程标识去重。
3. 按合并后的顺序对每门课点课程名链接（会 `_blank` 开 `learnCatalogNew.aspx`）。
4. 新标签里再点 `#courseHomeWorkNew`，见 [课程学习-形考作业入口.md](课程学习-形考作业入口.md)。

## 9. 硬坑

- 门户 URL 带学号和 `xhtoken`，日志、仓库、进度文案里都不许出现值。
- 课程链接 `target=_blank`，无头 Playwright 要接下一个 page/popup，或自己 `goto` 同 href。
- 课程名节点里有 SVG，不要用 innerHTML 当名字。
- 「记分作业：无」仍要进形考页确认，因为列表页还有「阶段性测验」。
