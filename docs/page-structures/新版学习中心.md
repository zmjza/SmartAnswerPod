# 新版学习中心 · 未来学习空间

2026-10-11 使用用户已登录的 Chrome 现场核对。旧版契约继续见 [学习平台-我的课程.md](学习平台-我的课程.md)，两版并存，按实际页面识别。

## 1. 路径与流程

| 页面 | 主机 / 路径 | 动作 |
| --- | --- | --- |
| 新版首页 | `aiedu.shou.org.cn/` | 主导航点「学习」 |

## 2. 已验证 DOM

| 对象 | 选择器 / 语义 | 说明 |
| --- | --- | --- |
| 主导航学习按钮 | `nav[aria-label="主导航"] button[aria-label="学习"]` | 页面另有移动端学习按钮，必须限定主导航 |
| 课程列表 | `[aria-label="课程列表"]` | 独立滚动区域，当前样本全部 8 门课程卡位于 DOM（包括视口外卡片），不能写死数量；不同账号是否分页或虚拟列表待证 |
| 课程卡 | `[data-learning-course-card]` | `article`，没有课程 href |
| 选中课程 | `[data-learning-course-card-active="true"]` | 切课后变化 |
| 课程标识 | `data-learning-course-ref` | 新版不透明标识，不等于旧站 courseOpenId；仅运行时用于定位卡片 |
| 切课按钮 | `button[aria-label^="切换课程："]` | 空按钮，名称在aria-label，视觉标题是同一卡片中的h3；真实8张ARTICLE中的辅助按钮无可视面积，物理click会超时 |
| 中栏 | `[aria-label="课程学习空间"]` | 切课后先显示「正在加载课程学习空间…」，旧任务 DOM 被移除 |
| 课程任务区域 | `[role="region"][aria-label="课程任务"]` | 已加载内容所在区域 |
| 对应课程容器 | `div[aria-label="课程名 课程任务"]` | 无 role 的外层 div，在非空和空态均存在；用于确认已经切到对应课程 |
| 非空任务列表 | `[role="list"][aria-label="课程名 课程任务"]` | 内层 div，与外层同名，只有有任务时存在；不要无条件等这个节点 |
| 任务行 | `[role="listitem"][data-task-tree-node-kind="lesson"]` | 包含任务标题、确认按钮和跳转按钮 |
| 正确跳转按钮 | `button[aria-label="去完成：完成课程形考作业"]` | 另有在线学习和成绩查询的「去完成」，不能按位置或短文案点 |
| 完成确认按钮 | `button[aria-label="我已完成：完成课程形考作业"]` | 会改变任务状态，自动化不得用它代替跳转 |
| 状态筛选 | 中栏 `button[data-figma-segmented-tab-key]` | key 为 `active` / `completed` / `overdue`，选中态 `aria-pressed="true"`；真实 DOM 为按钮，不能用 role=checkbox 定位 |
| 更多课程详情 | 中栏 a，文案「查看更多课程详情 »」 | 指向旧学习目录，可核对课程身份；不能根据新版 ref 拼旧站 ID |

## 3. 当前兼容实现

`electron/core/selectors.ts`、`electron/login.ts`、`electron/detect.ts` 与 `electron/runner.ts` 已接入以下流程。源码实现事实与真实产品验收分开记录。

1. 登录按真实主机／路径和结构识别：旧版为 `learning.shou.org.cn/scenter` 及课程Tab；新版为 `aiedu.shou.org.cn/`、`/learning`或`/learning/` 及主导航／课程列表。所有登录成功分支共用就绪检查，新版首页点学习，学习页等待课程区域；加载、明确无课程和读取失败分开处理，未知页面明确失败。现有IAM与门户入口沿用，不维护账号版本白名单。
2. 新版读取左侧全部已挂载卡片的ref和h3，按DOM顺序逐课串行采集，包括视口外卡片。按当前ref限定唯一切课按钮，核对完整aria-label且拒绝disabled；当前卡片尚未active时才调用DOM `button.click()`，已经active则复用当前加载过程，避免重复触发切课产生双响应竞态；这一方式针对学校无可视面积的辅助按钮，不修改学校DOM／CSS。缺ref、空名称或重复ref明确失败。
3. 普通课程切课后等待该ref卡片active、加载文案消失和对应课程无role外层容器内已有任务行，或当前筛选对应的明确空态；明确第三方嵌入按下方CHG-001单独判定。外层容器可能早于内容出现，上一筛选的空态不能算新筛选就绪。依次核对active／completed／overdue的aria-pressed选中态，空态无需内部role=list；找到精确形考入口便停止检查其它筛选。不启用必做过滤，不点击「我已完成」，不依据左右栏进度跳课。
4. 形考按钮限定在当前课程外层容器；点击前注册popup等待，等新标签到达旧站最终 `HomeWorkNew.aspx` 并完成DOM加载。核对HTTPS、主机、路径、课程参数，与当前中栏真实目录链接核对旧站课程身份。参数名兼容大小写，保留原URL；不得根据课程名或新版ref猜旧站参数。
5. 返回既有 `{name, href, key}`，key取旧站课程参数，重复身份去重，同名不同身份保留。`detectCourse` 接受目录及直接列表两入口，最终列表再次核对主机、路径和课程身份；两块作业、日期、次数、满分、预览和历史判定共用。runner在入口完整采集后沿用独立旧站页面并行检测，保留两工作模式与课程范围。
6. `listCourses` 与 `detectCourse` 接收runner的 `AbortSignal`。普通课程入口缺失、错课或加载失败明确报错，不返回残缺课表冒充成功；popup等待的监听、计时器及abort监听在finally清理并关闭本次标签，目录页始终关闭，检测失败时已打开的本次预览页一并清理。停止沿用账号独立中止与浏览器名额释放。
7. 旧版独立置顶形势与政策课、Tab内课程、收藏排除、顺序、课程身份去重及形考检测保留。

### 第三方嵌入答题课程

2026-10-12 Chrome只读核对《招聘与人才测评》：当前ref卡片active；学习空间没有课程任务region，只有一个 `iframe[title="课程学习空间"]` 和一个文本为「在新窗口打开」、`target="_blank"` 的a。a没有aria-label，其href与iframe.src完全一致，目标为HTTPS第三方主机 `sou.aihaoke.net`、路径 `/api/auth/unified/toAuth`；不记录认证参数值。

按PRD 1.3／CHG-001，上述结构确认属于当前课程时直接判为暂不支持，第三方加载提示或错误不阻断扫描，无需等待其加载或认证成功；第三方URL不得带用户名密码，也不得是 `shou.org.cn` 或其子域。不限定当前第三方域名或课程名称。保留课程行，以ref的SHA256形成独立 `unsupported:` key，`href`为空，附 `unsupportedReason`。产品显示「新答题界面暂时不支持，等后续开发」，检测与执行跳过该课，选课／停止保留提示，其他课程继续。普通缺入口、错课、未知壳及普通任务加载错误仍失败；不打开第三方顶层窗口，不开发其认证或作答。

切课前记录学习空间iframe节点、src及当时active ref。若目标课已active，或切课后出现新iframe节点／新src，可确认嵌入属于本课；若切课时仍是上一课同节点／同src且存在加载或错误提示，继续等待，不跳过新课，也不将旧错误立即归到新课。加载／错误消失且严格第三方结构仍在时，可接受学校复用同iframe与同src的正常就绪结果。该节点对比不读取第三方内容，不保存URL参数。

## 4. 与旧版的差异及误判风险

| 项目 | 旧版 | 新版 |
| --- | --- | --- |
| 入口 | `/scenter` + 我的课程 Tab | 首页点学习，进入 `/learning` |
| 课程节点 | `.course-item` 内课程名链接 | `article[data-learning-course-card]` 内空按钮 + h3 |
| 课程 ID | 直接读课程链接参数 | 新版 ref 不能当旧站 ID，需现场切课后核对旧站链接 |
| 形势与政策 | 旧样本为 Tab 外独立置顶卡，需额外合并 | 本次样本为左侧普通课程卡，位于列表末尾；同样有形考任务 |
| 进入形考 | 课程目录再点 `#courseHomeWorkNew` | 准确形考任务的「去完成」直接打开 `HomeWorkNew.aspx` |
| 后续作业 | 既有列表、预览、作答、历史 | 本次跳转页沿用既有结构 |

- 新版右侧「记分作业」显示「暂无作业」不等于真实旧站形考列表为空。本次中国近现代史纲要右栏为空，但从形考任务跳转后，旧站网上记分作业列表有两行。必须进入真实列表判定。
- 左栏百分比与右栏学习进度不是作业完成状态；不要依此跳过课程。
- 学习页共有三个相同视觉文案的「去完成」：在线学习、形考作业、形考成绩。准确的 aria-label 比按钮顺序稳定。
- 点击形考「去完成」后，短暂出现「正在处理：完成课程形考作业」，且同一任务组多个按钮会禁用；最终仍留在新版学习页，新标签打开旧站。不能只检查原页 URL。
- 状态筛选的原生无障碍树显示为 checkbox，但实际 DOM 是 `button[type="button"][aria-pressed]`。现场按 role=checkbox 定位没有匹配；应使用中栏限定的 `button[data-figma-segmented-tab-key="completed"]` 等选择器。
- 当前形势与政策样本切到已完成／已逾期分别显示「暂无已完成的课程任务。」「暂无已逾期的课程任务。」；空态保留课程名外层容器，移除内部 role=list。等待 role=list 会把正常空态误判成加载超时。
- 当前「只显示必做」未勾选。自动化读取全部课程任务时不要自行打开该过滤；该控件只过滤当前任务列表，不代表左侧课程总数。
- `data-task-tree-node`、`data-task-tree-node-task-id`、`data-learning-course-ref` 是动态值；不要把当前账号值写进选择器或源码。
