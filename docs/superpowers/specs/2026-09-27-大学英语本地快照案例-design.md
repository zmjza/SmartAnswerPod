# 大学英语本地快照案例设计

目标：保存当前 Chrome 中大学英语作答页的脱敏高保真本地 HTML，用于题型识别、答题和题库提取相关内部测试。

方案：保留当前页面五个栏目、真实题干、选项、表单层级和可见布局；移除用户身份、隐藏字段、临时令牌、真实地址和外部脚本；在页面末尾加入只访问本地 DOM 的交互脚本，模拟栏目跳转、题目选择、下拉匹配、折叠和提交状态。

边界：本地案例不执行真实扫码、服务器保存、真实批阅或外部音频请求；提交按钮只显示本地模拟结果。页面资源改为内嵌或本地可用资源，避免依赖学校服务器。

验证：在同一桌面尺寸打开本地 HTML，检查五个栏目、15 个顶层题目、10 个匹配下拉和表单结构；再点击每类控件，确认没有外部请求并能看到本地状态变化。
